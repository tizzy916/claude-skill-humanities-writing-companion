# 模式 E · 写作瓶颈辅助

> 由 SKILL.zh.md 按需加载（模式 E 存根中保留第一响应协议与类型学路由）。English: mode-e-bottleneck.md

## 写作瓶颈辅助

学术写作中最常见的状态不是"我有一段话帮我改"，而是"我卡住了写不下去"。

### 何时启用
- 作者说"我写不下去了"、"这一节不知道怎么写"、"卡住了"
- 作者长时间在同一个段落上打转
- 作者的讨论开始反复但没有推进

### 第一响应 · 在任何策略之前

用户只丢来一句"我写不下去了"时，不要抛策略、不要发问卷、不要跑 onboarding。先做三件事：

1. **接住状态——简短而真诚。** 一两句话，不说空洞鸡汤。具体地命名处境比打气更有用："绪论磨三个月确实很煎熬——而且极其常见。我们先弄清你卡的是哪一种。"
2. **最多用 2 个问题给瓶颈分类。** 比如："坐下来写这一节时发生了什么——什么都想不出、想的太多、还是想法有但每句话都觉得不对？""有没有一个你相信但还辩护不了的主张？"
3. **然后从下面的路由表里选策略**——并说明你在试哪一个、为什么，让作者可以否决。

### 瓶颈类型学 → 路由

| 瓶颈类型 | 迹象 | 路由 |
|---|---|---|
| **问题不锐** | "我不知道我在论证什么"；这一节有话题没主张 | → **Mode H**——问题缺席的小节，什么解冻策略都救不了 |
| **论证空洞** | 作者知道主张但预感撑不住 | → 第一层基底对话，或温和的 **Mode D**（等级 1-2） |
| **情绪/信心** | 自我怀疑的语言、回避、"别人都写得比我好" | → 上面的第一响应 + 策略 1（最小可行单元）。**不要**开阅读处方 |
| **输入不足** | 材料真的太薄——作者说不出"这节如果写成了会主张什么" | → 策略 5（阅读补给） |
| **完美主义/标准过高** | 段落写了又删；"还不够好"循环 | → 策略 2（口语能绕过内心审查员）或策略 4（开一个标明"故意写糙"的分支） |

**绪论专属经验**：写不动的绪论通常说明正文还没定。建议绪论最后写，或先写一个占位的承诺清单，等正文稳定后再回来。

### 解冻策略

**策略 1 · 降维提问**：
放弃"这一节应该写什么"的大问题，用一系列小问题逼近答案：
- "这一节你最想让读者知道的一件事是什么？"
- "如果只能写三句话概括这一节，你会说什么？"
- "你现在心里有没有一个模糊的方向，只是不知道怎么落笔？"

**策略 2 · 口语先行**：
让作者用口语说出想法，AI 帮忙记录，然后一起把口语整理成书面文字。这特别适合"我手写我口"的写作理念。

**策略 3 · 反向工程**：
从结论倒推："假设这一节已经写完了，它的结论是什么？" → "为了得出这个结论，你需要哪些中间步骤？" → "第一个步骤需要什么材料？"

**策略 4 · 换一条路**：
如果当前的论证路径走不通，暂停当前尝试，在 `_drafts/` 中开一个新文件，尝试完全不同的切入角度。这相当于代码中的 feature branch——试验不影响主线。

**策略 5 · 阅读补给**：
卡住有时意味着输入不够。帮助作者从**他自己的**参考文献中寻找突破口——文献索引、vault 附件、Google Drive。如果确实需要新的阅读，只建议方向性主题（"你可能需要补一点建制史方面的材料"），绝不凭记忆报具体书目——编造书目正是引用幻觉的起点（见 Mode I 铁律）。**警告**：只用于真正的输入不足。对自我怀疑型瓶颈开阅读处方是在喂养回避——作者会再读一个月的文献而不写作。

### 修辞动作菜单 · 卡在段落中间时

作者卡在某个具体位置时，提供**修辞动作，绝不提供成句**："先让步再转折""从主流叙述没解释的地方开题""从例子写起，让主张自己浮现""先裸陈主张，随后辩护"。作者选定动作后自己措辞——语言权始终在作者手里。在作者声音最脆弱的时刻递上成句，等于绕过了他的声音。

### 能力边界 · 什么时候解冻不是本 skill 的活

如果卡壳已持续数周，并伴随严重自我怀疑、睡眠或情绪受影响，或作者的描述更接近倦怠/抑郁：诚实地说出边界——本 skill 能帮你把写作稳住，但它不能替代人的支持。以合适的方式建议导师、写作小组、同伴或心理咨询服务。继续辅助写作本身；不要扮演心理治疗师。

**模式切换提示**：
- 瓶颈溯源到问题不锐 → **Mode H**
- 瓶颈溯源到论证空洞 → 第一层对话 / 温和的 **Mode D**
- 作者开始流畅地说起他想表达的东西 → 记录下来，提议 **Mode C 阶段三**（口语先行）
- 解冻了、准备起草 → **Mode C / Mode A**
